## Random Guesser
A Yr.10 python project of mine, further updated through Yr11 for more features. This program is a 2-way round guessing game, where you guesss a number, or the computer tries to guess yours User has to try to guess a number between 1 and 100.
# Features
    * Time delays used for a smoother reading for the user instead of a block of text just outputted straight away.
    * Defensive design used to prevent use of strings for a integar input.
    * Range filtering used to help user to pick an actual number between 1-100
    * Seperates genuine attempts to guess number from a failed attempt.
    * User can replay the game if they want to beat their high score.
    * High Score system if they user can guess in less attempts.
    * User can guess to number or the computer can guess the user's number.
# How to Play
1. Install Python 3 if it is not already installed. This game uses only Python's standard library, so no additional packages are needed.
2. Download the repository.
3. Open Terminal or Command Prompt in the downloaded repository folder—the folder containing `Start.py`. If you used the clone commands above, you are already in that folder.
4. Run the game:
   - macOS/Linux: `python3 Start.py`
   - Windows: `py Start.py`
