## Random Guesser
A Year 10 Python project of mine, further updated through Year 11 for more features. This program is a two-way round guessing game, where you guess a number or the computer tries to guess yours. The user has to try to guess a number between 1 and 100.

# Features
* Time delays used for smoother reading instead of a block of text just outputted straight away
* Defensive design used to prevent the use of strings for an integer input
* Range filtering used to help the user pick an actual number between 1–100
* Separates genuine attempts to guess the number from a failed attempt
* User can replay the game if they want to beat their high score
* High-score system if the user can guess in fewer attempts
* User can guess the number, or the computer can guess the user's number

# How to Play
1. Install Python 3 if it is not already installed[cite: 9]. This game uses only Python's standard library, so no additional packages are needed
2. Download or clone the repository
3. Open Terminal or Command Prompt in the downloaded repository folder—the folder containing `Start.py`
4. Run the game:
   - macOS/Linux: `python3 Start.py`
   - Windows: `py Start.py`
